# 评审范例：《雨覆孤台》（我们生成的本，2026-10-20）

> 目的：给 rubric 一个真实样例，说明"分数怎么来的"。
> 评审对象是**我们自己生成的本**（3 人、44 条线索、7 张图），不是拿真本当范例。

---

## 打分

| 维度 | 分数 | 依据 |
|---|---|---|
| 一、诡计成立性 | **3 / 3** | 见下 |
| 二、误导可证伪性 | **2 / 3** | 钢笔那条的排除是"缺证"而非"正证" |
| 三、线索克制 | **3 / 3** | 44 条线索全是事实陈述，零结论化措辞 |
| 四、唯一锁定 | **2 / 3** | 缺 1–2 条仍能推出周福，但会剩 1–2 个候选 |
| **合计** | **10 / 12** | |

---

## 维度一为什么给满分

手法共 7 步，**每一步都有 2–3 条线索托底**，而且出现了"反驳型线索"
（不是描述凶手做了什么，而是**堵死其他解释**）：

| 手法步骤 | 支撑线索 |
|---|---|
| 凶器是铜扳手 | A17（现场铜扳手沾暗红痕迹）、B8（五金手册：铜扳手 1.2kg 可致颅骨凹陷伤） |
| 凶手手上有铜锈 | A3（周福袖口新鲜铜锈）、B1（伤口边缘铜锈）、B2（表壳内侧铜锈） |
| 死亡时间 22:17 | B2（怀表停在 22:17）、**B3（机芯未进水、日误差≤1min → 22:17 可信）** |
| 用排水管水声掩盖 | B6（阀门全开、干土区）、B7（阀门手柄有周福布料纤维）、**B9（气象志：水流 65 分贝可盖过声响）** |
| 把挂钟拨慢 20 分钟 | B4（后盖撬痕 + 齿轮拨动 + 读数比怀表慢 20 分）、B22（螺丝刀碎屑与撬痕材质一致） |
| 钢笔/草帽是搬过去的 | A12、A13、B17（两物无血迹、离尸体 5 米） |
| 周福确实上过天台 | A15（鞋印磨损仅与周福吻合）、B14（袖口水泥灰同天台）、B18（扶手鞋印朝下） |

**B3 和 B9 是这份稿子最像真本的地方**：它不满足于"给出一个可能"，而是主动排除
"怀表被雨淋坏了""水声盖不住"这两个反驳。真本（344）里也有同款写法。

---

## 维度二为什么扣 1 分

三条误导分别是：

1. **林砚的钢笔**落在天台入口（A12）→ 排除靠 A15（鞋印只与周福吻合）
2. **张顺的草帽**落在天台入口（A13）→ 排除靠 B16（张顺鞋底只有煤灰，无天台灰尘）
3. **22:45/22:50 敲门无人应**（A10、A11）→ 排除靠 B4（挂钟慢了 20 分钟）

第 2、3 条是**正证**（有线索直接说明"他没去过""时间被篡改了"）；
第 1 条是**缺证**（"没有他的鞋印"）。按锚点"排名靠后的排除方式不能只靠没人提"，
所以扣 1 分。

**改进办法**：给林砚补一条反向线索，例如"林砚的鞋底沾有授课室的粉笔灰但没有天台泥土"
（与 B16 对仗），把缺证变成正证。

---

## 维度四为什么扣 1 分

要锁定周福，关键线索是：A15（鞋印）+ B14（水泥灰）+ B7/B5（纤维）+ B2/B3（怀表）+ B4（挂钟）。

试删：
- 删 A15（隐藏线索，需先搜 A14）→ 鞋印无法归属，但 B14+B7+B5 三处微量物仍指向周福 → **仍能推出**
- 删 B7 与 B5（两处纤维）→ A15+B14 仍指向 → 仍能推出
- 删 B2/B3（怀表）→ 死亡时间失去锚点，挂钟慢 20 分钟这件事变得无法证明 → **推不出**

所以"缺任意一条就无法区分"不成立，给 2 分。
**改进办法**：让 A15 成为必需（例如把 B14 的水泥灰写得也有第二种解释），
逼玩家必须拿到隐藏线索才能定案。

---

## 与真实语料对照（粗基线）

抽 3 本真实语料按同一标准自评，大致落在 **8–11 分**：
- 诡计成立性普遍 2–3
- 误导可证伪性普遍 2–3
- 线索克制 2–3（有本会写"这说明……"）
- 唯一锁定 2–3

**这份 10 分落在真本区间内**，与我们此前的印象（"我们只在结构上追平"）不同——
说明物证链这一层，我们的提示词已经做得不错了。
剩下的差距更可能在**诡计的意外性**（真本有"啊"的一下，我们偏"工程量"），
这一点 rubric 测不出来，只能人读。
