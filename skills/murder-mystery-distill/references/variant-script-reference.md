# 变格 / 机制本结构参照：《出逃连体村》

> **定位**：这不是"又一个本格样本"，而是**另一种写法**。用于回答"什么时候不该用本格模板"。
> **禁止**把它的数字混进 `distributions.md` 的本格中位数——它是极端值（真相体量是语料中位的 43 倍）。
> 来源：`D:\play game\剧本杀剧本资源合集\出逃连体村（全套）`，2026-10-20 用 MinerU OCR 后量化。

## 一、它的真实体量（1 本，实测）

| 指标 | 出逃连体村 | 本格语料中位 | 倍数 |
|---|---|---|---|
| 总字数 | **132,927** | 10,993 | 12× |
| 角色本数 | 8（含故事本/案件册/论破） | 6 | — |

**第一个反常识**：它 71.9k 字的手册、28.3k 字的真相，**却没有一条"隐藏线索"**。
它用**道具**替代了我们的"深入调查"机制 —— 见下。

## 二、结构上的四个差异（这才是值得学的）

### 差异 1：用"道具解锁"代替"隐藏线索"

「魔纸」出现 **167 次**、「紫光」**30 次**。玩法是：某些信息写在特制纸上，
**必须用紫光灯照才会显形**（手册里有明确的主持人操作话术：

> "【随后主持人用紫光灯照射村医的线索卡：《村医拿到的魔纸》】"

对应到我们的模板：我们用 `（发现隐藏线索，可深入调查）` 的父子线索对。
**道具解锁是它的等价物**，但更"实感"：玩家手里有个东西可以操作，
而不是"再花一次调查机会"。

→ 可借用：给部分隐藏线索配一个**实物道具动作**（紫光灯/透光卡/拼合），
  在同一份剧本里混用两种解锁方式，能缓解"每次深入调查都一样"的重复感。

### 差异 2：真相不是一次揭示，而是**连续推翻**

「推翻」出现 8 次，手册里明确写：

> "刘莹案的结论是否需要推翻？如需要，请找出真相！"
> "半仙案、王芜莲案的结论是否需要推翻？如需要，请找出真相！"
> "剧情任务1：总结新线索　1、密室不是村警制造的，他的下体是睡觉时被人刺伤的。
>  结论：翻窗的另有其人，凶手偷袭了村警想要栽赃他。"

**它有三层**：上半场给出"看起来完整"的结论 → 中场推翻一层（多为共犯/视角错位）
→ 终场再推翻一层（真凶与动机）。

→ 可借用：把我们的"真相复盘"从**一次性**改成**分段释放**：
  第一轮搜证后给一个"看似成立"的官方结论（由 NPC 村警/村长给出），
  第二轮的隐藏线索专门用来推翻它。这比"从头就让大家猜"更有戏剧性。

### 差异 3：变格设定，用"人格切换"制造不在场

「连体」400 次、「人格」37 次。连体人共用一个身体，两个人格轮流主导
（朱大智 ⇄ 朱若愚、白沐 ⇄ 白笙、李时 ⇄ 李珍）；村医可以让某人"暂时失去意识
（即切换人格）"。

**它的不在场证明是"人格层面"的**：身体一直在场，但"这个人"不在场。

→ 这是变格本的标准做法，本格语境下不成立（我们的 `logic-checks` 会判它物理不可能）。
  **提醒**：如果我们以后支持变格，`checkTrickObservability` 这类"物理可行"校验必须先放行设定内的超常规则，
  否则会把合法设计全判成错误。

### 差异 4：线索卡是"信息总结卡"，编号但不分地点

「信息总结卡」4 次，形式是：

```
1、村警最近体虚，唾得沉，于是把床搬到了窗边……
2、案件册最后朱大智开始他的推理时，众人发现他的珠子不见了。空心木头做的珠子，有99颗……
3、许一诺周远第二天在半仙家向大家分享了半夜看到的景象。
4、村医可以让朱大智或朱若愚暂时失去意识（即切换人格）。
```

**编号 + 无地点字段 + 按"信息"而非"搜证位置"组织**。我们的线索是 `A1/B1 + 发现地点`。
它这种更适合"公开共享"式搜证（大家把拿到的信息卡念出来拼图），而不是"各自搜房间"。

→ 可借用：给**证言类线索**单独做一组"信息总结卡"，编号但不写地点，
  用于第二轮"集中推理"阶段，和第一轮的"按房间搜证"形成两种节奏。

## 三、不能照搬的地方

| 别照搬 | 原因 |
|---|---|
| 真相 28k 字 / 手册 72k 字 | 我们的生成管线单段耗时已经 75–110 分钟；这个体量写不完也校验不了 |
| 8 个"角色本" | 它把故事本/案件册/论破都算进去了，实际玩家角色 5–6 个 |
| 人格切换式不在场 | 需要变格支持，`logic-checks` 现在会判为物理不可能 |
| 无时间线的推理 | 它靠"信息卡拼图"；我们的模板与校验都建立在时间线之上，混用会两头落空 |

## 四、一句话结论

**可以蒸馏，但只能当"结构参照"，不能当分布样本。**
它最值得借的是两点：
1. **道具解锁**作为隐藏线索的另一种形态（缓解机制重复感）
2. **分段推翻**（先给官方结论，再用隐藏线索推翻）作为真相揭示的节奏设计

其余（超长体量、变格设定、无时间线）都在我们当前管线能力之外，
强行模仿只会让生成质量下降。
